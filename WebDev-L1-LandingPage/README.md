# WebDev-L1-LandingPage

StreamFlix is a fictional streaming platform landing page created as part of the Oasis Infobyte Web Development Level 1 internship.

## Technologies Used

- HTML5
- CSS3

## Features

- Responsive navigation bar
- Hero section with call-to-action buttons
- Trending movies section
- Features section
- FAQ section
- Responsive design for mobile and desktop
- Sign-in interface

## Project Structure

- index.html - Main webpage
- style.css - Website styling
- README.md - Project documentation

## Project Type

Oasis Infobyte Web Development Level 1 Internship - Task 1: Landing Page
